# PasswordGenerator
A fast and customizable password generator built with React and Vite. Users can generate secure passwords with adjustable length (8-100) and optional numbers or special characters. Includes clipboard copy functionality and uses React hooks (useState, useEffect, useRef, useCallback).

Features 🚀
✅ Generates random passwords with each click.
✅ Minimum length: 8, Maximum length: 100.
✅ Includes checkboxes to add numbers and special characters.
✅ Uses useRef, useEffect, useState, and useCallback hooks.
✅ Password is copied to the clipboard automatically.
✅ Built with React Vite for fast performance.

Usage 📝
Select the password length (default: 8 to 100).
Check the options for numbers and special characters.
Click "Generate Password" to get a new password.
The password will be automatically copied to your clipboard.


Technologies Used 🖥️
React (Hooks: useState, useEffect, useRef, useCallback)
Vite (for fast development)
CSS (for styling)
